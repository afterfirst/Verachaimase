# Kotoba Study: Project Summary

## Application Overview
**App Name:** Kotoba Study
**Description:** Kotoba Study is an AI-enhanced Japanese language learning tool designed to simplify reading complex Japanese texts. It converts images (via OCR) or raw text into interactive, tokenized breakdowns that display grammatical roles, readings, pitch accents, and JLPT levels simultaneously.

## Key Features
- **Intelligent Tokenization:** Breaks down Japanese sentences into meaningful words with Part-of-Speech tagging.
- **Visual Pitch Accent:** Interactive SVG-based pitch diagrams for every word to master standard Japanese pronunciation.
- **Multi-Modal Input:** Supports direct text input and image uploads through a robust OCR engine.
- **Linguistic Insights:** Instantly identifies JLPT levels (N1-N5) with color-coded visual cues.
- **Dictionary Integration:** One-click lookup connecting words directly to Jisho.org for detailed definitions.
- **Personalized Progress:** Firebase-powered history tracking and a "Favorites" list to save difficult vocabulary for later review.
- **Fluid Animation:** Seamless UI transitions powered by `motion` (Framer Motion) for a premium feedback experience.

## Technical Specifications
- **Framework:** React 19 (Frontend) + Express (Backend)
- **AI Integration:** Google Gemini 1.5 Pro for linguistic analysis and translation.
- **Data Persistence:** Firebase Firestore for user history and favorites.
- **Authentication:** Firebase Authentication for secure multi-device access.
- **Styling:** Tailwind CSS 4.0 for a high-performance, modern aesthetic.
- **External APIs:** OCR.space for image text extraction, Jisho.org for definitions.
